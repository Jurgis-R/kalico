# G68/G69 XY work-coordinate rotation

This branch adds a modal XY work-coordinate rotation to Kalico's G-code
movement layer.

## Commands

```gcode
G68 X100 Y75 R2.0   ; rotate programmed XY coordinates +2 degrees CCW
                    ; about the centre (100, 75) in the current work frame
G1 X150 Y75 F600    ; moves to the rotated endpoint
G69                 ; cancel rotation, preserving the current machine position
```

- `X` and `Y` are required centre coordinates in the current G-code frame.
- `R` is required and is in degrees; positive angles are counter-clockwise.
- Only XY is rotated. Z, E, feed rate, and additional axes are preserved.
- G68 is rejected until Kalico reports the printer ready.
- Homing cancels the rotation to avoid retaining a stale work frame.
- The existing `[gcode_arcs]` implementation still segments G2/G3 into G1
  moves; those segments are transformed, but this is not native arc interpolation.
- This change transforms G-code moves routed through `GCodeMove`. It does not
  claim to transform direct toolhead operations or arbitrary third-party probing
  commands that bypass G1.

## Safety / validation

Test first with motors disabled or in a simulator, then with the tool clear of
the workpiece. Confirm the positive rotation direction, pivot, G54/G92 offsets,
G90/G91 behavior, G68/G69 position continuity, SAVE/RESTORE_GCODE_STATE, and
interaction with bed mesh or any other configured move transform. Do not cut
until the exact machine configuration has been checked.
